# 💡 Tooling & Testing Kit - Examples & Usage Guide

This directory contains concrete examples demonstrating how to use the **Tooling & Testing Kit** for static analysis, codebase hygiene, and AST manipulation.

---

## 📁 Included Files

- **`sample_target.py`**: A sample Python file containing intentional code smells (dead code, unawaited async tasks) to demonstrate scanner capabilities.
- **`scanner_output_example.md`**: Sample formatted audit report generated by `kit-hygiene`.

---

## 🚀 Quick Execution

### 1. Run Hygiene Scanners on Sample Target

```bash
# Execute hygiene static checks
python hygiene/scanners/run_all.py --scripts
```

### 2. Run AST Refactoring Tools

```bash
# Add an import statement using AST
python tools/add_import.py examples/sample_target.py "import typing"

# Replace a function safely
python tools/replace_function.py examples/sample_target.py calculate_user_metrics "def calculate_user_metrics(data: list) -> dict:\n    return {'total': sum(data), 'count': len(data)}"
```

### 3. Run Test Suite

```bash
# Run pytest on example target tests
pytest tests/examples/
```
